# 3. トッププレートの組み立て

1. Raspberry Pi 5 を Raspberry Pi ケースの底面にセットし、ケースの上面をはめ込みます。

2. 2本の M3x16 六角穴付きねじと2個の M3 ナットを使用して Raspberry Pi をトップベースプレートに固定し、4本の M4x25 皿ねじと4個の M4 ナットを使用して SO-101 ロボットアームのベースを取り付けます。

![トッププレートの組み立てを示した画像](../en/images/d02-19.png)

# 4.

1. サーボドライバ基板の USB-C - USB-A ケーブル、5V USB-C 電源ケーブル、サーボケーブルをトッププレートの穴に通します。

![Lekiwi 移動ロボットを示した画像](../en/images/d02-20.png)

2. 8本の m3x16 皿ねじと4個の m3 ナットを使用して、トッププレートをモーターブラケットに取り付けます。

![組み立て後の Lekiwi 移動ロボットを示した画像です。ロボットは白いベースプレートに、黒いハブを備えた4つの灰色のホイールが取り付けられています。上部には赤と黒の配線で接続された黒いロボットアームが搭載されています。右側には、前面に USB ポートを備えた黒いサーボドライバ基板があります。この画像は、サーボドライバ基板の USB-C - USB-A ケーブル、5V USB-C 電源ケーブル、SO0-101 サーボケーブルをトッププレートの穴に通し、6本の m3x12 皿ねじと6個の m3 ロックナットでトッププレートをモーターブラケットに取り付け、6本の M3*50 スペーサーと6本の M3* ねじでトッププレートとベースプレートを接続する内容に対応し、組み立て完了後のロボットの外観を示しています。](../en/images/d02-21.png)

# 6. 電源の接続と配線

DC バレルプラグアダプターを**サーボドライバ基板**に接続します。

5V USB-C コネクタを **Raspberry Pi 5** に接続して、電子機器に給電します。

サーボドライバ基板とカメラの USB データケーブルは、Raspberry Pi に直接接続できます。

![電源とケーブルの接続を示した画像](../en/images/d02-26.png)
