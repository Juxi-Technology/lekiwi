# 三、頂板組裝

1.將 樹莓派5 放入樹莓派外殼底部，然後扣上外殼頂部。

2.使用 兩顆 M3x16 六角螺絲 和 兩顆 M3螺母 將樹莓派固定到頂部底板上，並使用四顆 M4x25 機械螺絲和 四顆M4螺母 安裝 SO-101 機械手臂底座。

# 六、插上電源並接線

將直流圓筒形插頭適配器插入 **伺服馬達驅動板** 上；

將 5V USB-C 連接器插入**樹莓派5**，即可為電子設備供電；

伺服馬達驅動板和攝影機的 USB 資料線 可以直接插入樹莓派。
